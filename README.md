# MindPhase-M: A Multilingual Empathetic Chatbot Fine-Tuned with LoRA Adapters

## Project Overview
MindPhase-M is a multilingual empathetic chatbot developed as a final-year B.Tech Computer Science and Engineering project. It aims to provide supportive and empathetic conversations for women's mental and physical well-being.

## Objectives
- Provide empathetic responses to users.
- Support multilingual communication.
- Offer a user-friendly conversational experience.
- Explore the use of LoRA adapters for fine-tuning language models.
